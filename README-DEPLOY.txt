TRADEX. Website V02 | Revision 25

Upload this ZIP to Netlify or open the extracted index.html in a browser.
The website is static and needs no build command or backend. Publish from
the folder containing index.html if deploying the extracted files.

Alpino, General Sans, Satoshi and Switzer load locally from assets/fonts.
The supplied official Fontshare webfont files are included for self-hosting
this website. The ITF Free Font License is in assets/fonts/ITF-FFL.txt.
Independent licensees obtain their own font copies directly from Fontshare.

The ZIP contains the full English and German company website, including Coming
in 2027 and all 12 team profiles. Team descriptions appear on mouse hover,
keyboard focus or tap. The hero montage and poster are included.

The website includes a noindex directive in index.html and _headers for
client review. Remove both when the approved website should be indexed.

Before public launch, confirm the two compound addresses and team bios
with TRADEX. The addresses shown under Germany and Austria are sample
data. Set the confirmed postal lines in config.js under locations.de and
locations.at. Set media.compound to approved site photography when it is
available. The present image is a visual stand-in for the actual facility.

Edit bilingual page copy in index.html and the team profiles in profiles.js.
Edit the hero video, portal links and motion settings in config.js. The
existing TRADEX. legal notice links are set in the bilingual footer.

R20 colour and artwork
The interface uses the V3.1 digital palette for the header, hero, ecosystem,
portal illustration, profile panels, Join and footer. The compound and
roadmap use editorial Midnight. The audience, purchasing and team sections
use the editorial light palette.

The header and footer use the client wordmark_light_ex.svg. Its viewBox
was adjusted to preserve the R19 display size. The opening gates, favicon,
hero and Join use the faceted X from the client full_light_ex.svg. The
client's FULL_dark_ex.svg contains identical X paths and gradients.
The two legacy SVGs tradex-primary-lockup.svg and tradex-decoration-x.svg
remain in the archive as unreferenced assets.

The client wordmark uses #00F5FF for EX. V3.1 specifies #06E4FE.
R20 preserves the supplied client artwork colours.
