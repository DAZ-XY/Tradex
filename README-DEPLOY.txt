TRADEX. Website | Netlify release v49 (mobile hero adjustment)

DEPLOYMENT
1. Open your existing site in Netlify.
2. Open Deploys and upload TRADEX_v49_NETLIFY_UPLOAD.zip as a new production deploy.
   (Use Netlify Drop only if creating a separate site.)
3. After it publishes, refresh the page on your phone. If an older version appears, reload without cache.

FILES
- index.html (HTML, CSS, JavaScript and locally embedded Montserrat + Inter fonts)
- assets/images (approved embedded/extracted image and SVG assets from v48)

CHANGE FROM v48
- Mobile hero no longer forces at least 91% of the viewport height.
- Hero height now follows the copy plus a compact, safe bottom margin.
- Car photograph sits higher behind the hero content.
- Desktop and tablet presentation remains unchanged.
- English and German copy, navigation and functionality are preserved.
