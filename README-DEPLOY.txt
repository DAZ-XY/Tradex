TRADEX. | R26 Netlify package

Upload the extracted folder containing index.html to Netlify. The static
site includes both MP4 files, their posters, photographs, fonts and the
font license. It needs no build command, environment variables or backend.

The selected R25 layouts and scroll effects carry through to this build.
English follows the supplied copy review marked (1). The German copy
reflects the corresponding changes. Both videos are silent background
loops. The compound has a gradient overlay for the text above it.

This package uses the R25 review settings for search indexing and the
sample logistics addresses from the supplied copy document.
