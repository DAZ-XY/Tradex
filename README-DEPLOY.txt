TRADEX. Website V02 | Tenth revision | Public configuration

Open index.html in a browser or host the extracted ZIP with index.html at the
web root. The package has no build or backend requirement. It retains noindex
in HTML and Netlify headers for pre-release review. Remove both once approved
for indexing. Use host-level access control for any draft review.

index.html has the bilingual site copy, source portrait mappings and links.
styles.css has the selected fonts and visual system.
site.js coordinates rendering, language, profile interactions and scroll progress.
config.js is the release control for media, outbound links, approved staff
records, official compound addresses and the Legal notice.

The private preview includes the illustrative compound photo, blank address
templates, draft staff profiles and proposed 2027 copy. Use the private
preview for review and the ZIP for public hosting after sign-off.

The supplied silent loop is enabled with landscape and portrait MP4 files.
Set the paths under media.hero if replacing it. Posters match both crops.
Set media.compound to approved photography. The portal illustration uses
editable anonymised milestone text in index.html. Do not add customer data.

Add official postal address lines to locations.de and locations.at. Set
urls.legalNotice to the approved legal page. Add only signed-off profiles
to approvedProfiles by person ID. Each supports bilingual bio and focus,
language codes, email and phone. Professional contact links appear only
when the approved profile contains them.

The proposed sections for 2027 were omitted from this ZIP. On approval, insert
the approved section markup before Team, add the footer anchor and enable
showComingIn2027 in config.js. The private HTML includes the section layout.

The registration destination is the dealer portal and includes the referral
parameter. The corporate site has no registration form.

Ubuntu Medium (500) is used for section headings. Ubuntu Regular (400) at
15 px is used for body copy. Oswald (630) is used in the hero and closing
headlines. Fugaz One is used for labels, indicators and technical type.
The original font files are self-hosted alongside their licence notices.

The motion settings in config.js define the reveal distances and the separate
hold after each scene reaches its last frame. Short screens use in-flow
reveals when the full composition cannot fit in a viewport.
